**openbranch** es un proyecto de documentación viva para desarrolladores — una guía compartida sobre buenas prácticas, flujos de contribución, patrones de pruebas, estrategias de Git y lecciones aprendidas en proyectos reales.

Es agnóstico al stack y construido por la comunidad.
